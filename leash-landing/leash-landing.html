🎮 How to Use Leash Before Coding to Get Alerts

Follow this step-by-step developer workflow to ensure your workstation is protected and your phone receives real-time approval alerts before your AI coding agent touches the terminal or files.

STEP 1 · LAPTOP CONTROL PLANE

Launch the Laptop Daemon

Open a terminal on your development workstation and start the background Leash daemon:

python -m daemon.cli server --port 8765
What happens:
  • The daemon launches the local control plane and opens the Leash Security Portal at http://localhost:8765.
  • A 6-digit single-use pairing PIN and cryptographic QR code appear on screen.
terminal: daemon server
$ python -m daemon.cli server --port 8765

python -m daemon.cli server --host 0.0.0.0 --port 8765

Prefix Agent Launch with daemon.cli run --

Before letting an autonomous agent execute tasks, prefix the launch command to attach the Leash guard:

python -m daemon.cli run -- claude
What happens under the hood:
Isolated Git Worktree Creates leash/<session-id> so uncommitted host changes remain safe.
Secure PATH Shims Injects shims for bash, sh, git, curl, npm, pip.
Restricted Token Master HMAC pairing secret never leaves the daemon.

Code Naturally While Leash Guards in Real Time

Safe Commands (Auto-Allowed):
Commands like cat file.py, ls -la, git status, or npm test execute at native speed without interruption.

📱 THREE SIMPLE CHOICES ON YOUR PHONE

Authorize or Block from Your Phone

You have full control with cryptographic verification. Choose an action to simulate the real-time response:

1. Slide to Approve Phone transmits HMAC-SHA256 signed ALLOW. Laptop unpauses agent in isolated worktree.
2. Tap Deny Phone transmits signed DENY. Laptop halts execution (exit code 126) with structured feedback.
3. Walk Away / Ignore If 30s timer expires without approval, Leash enforces Fail-Closed default (blocked automatically).

What it catches before it runs

A plain reason, every time

Each risky command becomes one sentence you can act on, not a wall of shell.

It remembers where an action came from

If the agent just read untrusted text, the next risky action is rated higher and shows the source line.

Secrets stay fenced

Reads of .env files, ssh keys and cloud credentials are blocked. Canary files raise an alarm if touched.

Packages are checked first

Look-alike names, brand-new versions and install scripts show up before anything installs.

One tap to rewind

Leash snapshots your repo before a risky approved action. Roll it back from your phone.

A receipt for your pull request

Every command, approval and block, written as Markdown.

It fails closed

If your phone cannot be reached, dangerous actions are denied.

What Leash is not

Leash is a checkpoint at the shell, not a sandbox. A determined attacker needs OS-level isolation too. We test bypass tricks against it and say what gets through.
